# modern-ml-labs
Modern ML Labs nace como una extensión práctica de mi formación en ciencia de datos. A partir de las bases estadísticas y de machine learning desarrolladas durante mi magíster, utilizaré este repositorio para explorar modelos y enfoques que todavía no había tenido la oportunidad de aplicar.

En cada laboratorio pondré a prueba una técnica nueva para mí, comparándola con modelos tradicionales o baselines consolidados sobre datasets reales. Además del rendimiento predictivo, analizaré aspectos como el preprocesamiento requerido, la complejidad del pipeline, el tiempo de entrenamiento y la interpretación de los resultados.

El objetivo no es desarrollar algoritmos nuevos, sino ampliar mi caja de herramientas y comprender, mediante experimentos reproducibles, cuándo estos modelos aportan ventajas prácticas y cuándo una alternativa tradicional sigue siendo suficiente.
